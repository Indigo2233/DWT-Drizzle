# 2.7.101-D 发布说明

对比基线：`v2.7.4`（线上最后一次同步，commit `136e6ba`）。
本版累计 103 个提交，35 个文件、+17480/−1206 行。

---

## 一、界面（分支 D 重做）

- 苹果式浅色主题：自绘圆角卡片、胶囊分段标签页、凸起高光按钮，正文限宽居中，DPI 自适应。
- 高级页路径行改 grid<small>（输入框吃剩余宽度 + 按钮固定列）</small>，实测到 640 px 宽窗口按钮不再被挤掉；修掉三处按钮被重复行号覆盖的问题。
- 限帧 / 裁剪边长不再记忆，启动恒 0；几何目录与彩机参考目录每次换素材自动重搜。
- 叠加日志自动存成 `<成品名>_叠加日志_<时间>.txt`，与成品同目录。

## 二、彩机 / CFA 全链路

- **真 CFA 直读**：不 debayer，按四相位直接投 drizzle 网格（与 PI 的 CFA drizzle 同类）。
- **逐通道输入识别**：素材若已按 `__R/__G/__B` 拆成单色帧，自动分成三组，不再误当拜耳马赛克
  <small>（旧版会把三色帧混成一组并按四相位取样，导致 1/4 采样 + 网格 + 横纹）。</small>
- **彩色通道平衡**改为可选，默认「不平」（与 WBPP 的 ChannelCombination 一致）；修掉乘性平衡把 R/B 放大 1.43/1.90× 造成的饱和星彩边。
- **高光保护**：接近饱和的像素取三通道均值，星点核心中性白。
- **按参考图标定亮度**（`--match-scale`）：成品可缩放到 WBPP master 的天空量纲，便于直接比对
  <small>（WBPP 的 master 普遍是输入的 0.70×）。</small>
- 自动输出 RGB 合成与预览图（`PWS_<名>_RGB.xisf`、`_RGB_preview.png`）。

## 三、网格与黑坑的根治（本版主线）

- **液滴边长按同色格点间距**：CFA 下同色样本间隔 2 源像素，2× 输出时相邻样本相距 4 输出像素；
  旧实现按 `pixfrac·s` 取边长，实测 6.16%（pixfrac 1.0）到 12.7%（0.8）的输出像素拿不到样本 → 2×2 黑网格。
- **2×2 去格点**：用四相位中位数估增益并归一，消除强拉伸下残留的细密网格
  <small>（用户 M101：相位差 0.90% → 0.064%；本机 78 帧：0.90% → 0.010%）。</small>
- **排异不再剔空像素**：所有样本都被剔的像素保留偏差最小的真实样本，不再写 0 造成「黑坑」。
- **未覆盖像素写 NaN**（交给自动裁边），不再用最近邻伪造。
- **两遍 drizzle**：第一遍按样本足迹保锐度，第二遍只对未覆盖像素放大液滴补相位（仍是真实样本）；
  实测内部空洞 32.96% → 0，总未覆盖 13.66% → 2.51%（全在边缘），噪声仅 +1.6%。

## 四、配准

- 锚点 80 → 240 颗，剔除贴边与最亮饱和星；三角形解加尺度先验 1±2%，拒绝 0.43 这类伪解。
- **漂移一致性检查**：位移偏离帧间趋势 >3 px 的帧判错配并排除（避免星点叠成双影/脱线），阈值 `DWT_DRIFT_PX` 可调。
- **稀疏星场判据**：绝对命中 ≥20 且亚像素残差 ≤0.6×rad 也可通过（80 颗星时 26% 不再被误杀）。
- **链式兜底 + 全局平差**：直配失败的帧先与邻居配准再复合；直配与相邻观测一起做加权最小二乘，解出 dx/dy/θ/ln 尺度，摊平链路误差。
- **参考帧自动回退**：参与率 <50% 时换星点最多的候选重解（修「16 帧只叠上 1 帧」）。
- 修「参考网格本身是 2× 上采样」被尺度先验误杀导致的全黑图（定心路径放宽到 0.4~2.5）。

## 五、GPU

- **wgpu 成为主后端**：灰度素材也走液滴散射画布内核，`auto` 不再因无 CUDA 掉回 CPU；移除 CuPy 依赖（包 153 → 76 MB）。
- **软件适配器过滤**：拒绝 WARP / lavapipe（否则比 CPU 还慢）。
- **回退可见**：日志出现 `[wgpu][fallback] reason=…` 即表示回退；正常应为 `backend=canvas fallbacks=0`。
- 修 canvas 后端 `n` 未定义导致的全量回退；分桶后端大缓冲超限改为按 `max_buffer_size` 切块。

## 六、权重与信噪比

- **吞吐权重默认关闭**（`flux_pow 2 → 0`）：HFG1-3 实测 O 通道天空 σ 1.4857 → 1.4241e-05（−4.1%）、FWHM 3.34 → 3.31；H 通道 2.4323 → 2.3916e-05（−1.7%）。
  <small>原因：天空背景下亮帧散粒噪声同样高，`S²` 已含逆方差，再乘 `T²` 属重复加权。</small>
- **真 CFA 下 A 上限 6**：A=10 时单帧逐像素独占权重可达 409×，小星周围出现 −2σ 黑坑（28.6%）；A=6 降到 0.5%。`DWT_A_KEEP=1` 可覆盖。
- 排异开/关对天空噪声几乎无影响（1.4857 vs 1.4875e-05），可放心开着去卫星线。
- winsor 尺度改用块中位数，卫星线穿过块时不被拉松。

## 七、稳定性与兼容

- memmap 默认落素材盘；重采样按行分块（峰值 11.2 → 1.0 GiB）；`cpu_count` 兜底；开机打印 CPU/内存/GPU 环境行。
- 成品有效性门禁：有效率 <5% 判失败并拒绝写盘（黑图不再流出去）。
- 环形缓冲跳过锚点迭代，全幅叠加段 −34%。
- 修「对齐输入」模式 `NameError: name 'p' is not defined`。
- 曝光归一日志自解释，支持 `DWT_EXPTIME_REF` 覆盖。

## 已知限制

- `--crop` 与 `--frame` 同时使用时倍率换算仍有偏差（未修）。
- macOS 包尚未按 D 线重建（旧包对应 2.7.19）。
- 真 CFA + 1× 输出下 PSF 空间均匀性弱于 WBPP（A≥14 时 spread 1.37× vs 1.15×）；需要 SXT 处理时建议 A ≤ 6。
