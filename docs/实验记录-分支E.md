## 结论

1. **排异开关对噪声几乎无影响**（1.4875 vs 1.4857e-05），所以「排异没生效 → 信噪比高」不成立。
2. 噪声损失主要来自**吞吐权重 T^flux_pow**：flux_pow 2→0 使 σ 从 1.4857 降到 1.4241e-05（−4.1%）。
   T 是逐帧信号水平；在天空背景主导时，亮帧的噪声也更高，
   而 `S²`（逆方差）已经把这件事算进去了，`T²` 等于对信号再乘一遍，属于过加权。
3. **A=14 + flux_pow=0 同时更锐更干净**：FWHM 3.31（比 3.34 好）、σ 1.4241e-05（比 1.4857 好），
   说明「清晰度加权」和「低噪声」并不冲突，冲突的是 T² 与噪声统计。
4. 与历史最高信噪比那版（1.3986e-05，FWHM 3.34）相比，我们现在差 1.8%，但 FWHM 更锐、且排异正常工作。
5. M101（78 帧真实 CFA）上 flux_pow 1 vs 0 结果逐位相同（σ 均为 9.5048e-05），说明该参数只在帧间信号差异明显时起作用。
